This is an example plugin for `emmui` which upon clicking a button retrieves your public IP address by querying a service.

If you want to develop your own plugin, it's recommended to copy the source for this as a basis. It uses `tsdown` to bundle everything you need into a single JS file that will serve as the plugin source. *Remember to list your dependency packages as `devDependencies`, otherwise they won't be bundled by default.*
